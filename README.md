
# 🎨 Interactive Portfolio

Welcome to **Vemula Bhavya’s Portfolio** — a sleek, interactive, single-page web portfolio showcasing my work, skills, and contact info.




## 📖 About

This is my personal portfolio website — designed to be interactive, responsive, and minimalistic. It serves as a digital introduction and a showcase of my projects, skills, and background.


## ✨ Features

- Smooth scrolling and navigation  
- Responsive design — works well on desktops, tablets, and mobile  
- Sections for: About, Projects, Skills, Contact  
- Interactive animations and transitions  
- Clean UI/UX, minimalistic aesthetics
